# Limitcode Pro

[Limitcode Pro](https://limitcode.jawuil.dev/?utm_source=github&utm_medium=docs)
is the fully autonomous version of Limitcode. It keeps the same
editor-native workflow as Limitcode OSS and adds capabilities for working
across a project.

## What Pro adds

- Project-wide file listing, searching, and targeted edits
- Approved shell command execution
- Web search and page fetching
- Reusable skills and MCP server connections
- Focused subagents and batched workflows
- Account sign-in for GitHub Copilot, OpenAI Codex, and Google Antigravity
- Automatic context compaction and snapshot-based undo/redo
- License-gated activation on up to three devices

Pro runs entirely inside Sublime Text with a configurable permission model. It
is distributed as a packaged release rather than source.

## OSS and Pro

Limitcode OSS is the focused, open-source pair programming agent: it works only
with files you have open and exposes a small, reviewable tool surface.
Limitcode Pro is the autonomous product for project-wide work. Both keep the
editor-native workflow inside Sublime Text.
