# Limitcode Docs

Public documentation and landing page for [Limitcode OSS](https://github.com/Jawuilp/Limitcode), built with [Just the Docs](https://just-the-docs.github.io/just-the-docs/) and deployed to GitHub Pages.

## Local development

```powershell
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000/limitcode-docs/`.
